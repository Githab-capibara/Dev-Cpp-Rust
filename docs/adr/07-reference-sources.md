# 07. Храним исходники Dev-C++ (Pascal) вне репозитория

- **Status:** Accepted
- **Date:** 2026-11-23
- **Deciders:** @Githab-capibara
- **Related:** [03. Формат `.dev` по первоисточнику](03-dev-file-format-from-source.md)

## Context

Для посимвольной совместимости (`.dev`, шаблоны, Makefile, MI) мы читаем
оригинальные исходники Dev-C++ на Delphi/Pascal. Dev-C++ распространяется под
GPL-2.0/GPL-3.0 с вкладами Embarcadero.

## Decision

**`reference/` не коммитим** (см. `.gitignore`): папка остаётся локальной для
разработки и сверки. Репозиторий devcpp лицензируем MIT OR Apache-2.0; в
README даём явную атрибуцию и ссылку на upstream. Производные данные (форматы,
шаблоны) воспроизведены по поведению, не копированием кода.

## Consequences

- **Easier:** чистый лицензионный след для MIT-проекта; нет перераспределения
  GPL-кода в нашем репозитории.
- **Harder:** новый участник должен сам раздобыть upstream для сверки; README
  обязан нести атрибуцию.
- **Given up:** ничего.
- **Migration:** n/a.

## Alternatives considered

- **Коммитить `reference/` как third-party:** отвергнуто — смешение лицензий в
  одном дереве без чётких границ действия копилефта.
